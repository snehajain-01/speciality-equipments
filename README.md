# Speciality Equipments

Industrial Water Treatment & Equipment Solutions website.

## 📌 About the Project

Speciality Equipments is a responsive business website designed to showcase
industrial water treatment products, services, clients, and company
information.

## ✨ Features

- Responsive website design
- Home, About, Products, Services, Clients and Contact sections
- Product search and filtering
- Product categories
- Contact form
- Admin panel
- Supabase database integration
- Client and product management
- Sitemap and robots.txt for SEO

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- REST API
- Responsive Web Design
